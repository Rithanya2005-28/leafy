    How it works
    
            
    
                
    
                    🖼️
                    
    Image processing
    
                    
    OpenCV resizes to 224 × 224, converts to RGB, applies Gaussian blur and scales pixels for the network.
    
                
    
                
    
                    🧠
                    
    Deep learning
    
                    
    MobileNetV2 transfer learning classifies the leaf species from the Kaggle leaf dataset.
    
                
    
                
    
                    🔐
                    
    Integrity check
    
                    
    Every upload is hashed with SHA-256, validated by extension, MIME type and size, and stored with a safe filename.
    
                
    
                
    
                    🌐
                    
    Client–server
    
                    
    Flask exposes REST endpoints for uploads, commands, model info and health checks, consumed by this UI.
